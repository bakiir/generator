
# 🎟️ Генератор Лотерейных Билетов для компаний Tez Tap(производители настольных игр) 

Генератор Лотерейных Билетов — это веб-сайт для участия в лотерее. Каждый участник получает уникальный номер-билет.  
Администраторы могут просматривать данные новых и ранее участвовавших пользователей, очищать их или скачивать в формате Excel.

## 🚀 Установка

```bash
git clone https://github.com/username/lottery-generator.git
cd generator
npm install         # или pip install -r requirements.txt
````

Настройте проект:

1. Скопируйте `.env.example` → `.env`
2. Укажите свои настройки (например, подключение к базе)

Запуск:

```bash
npm start           
```

### Требования:

* Node.js (16+) 
* База данных: MongoDB или SQL

## 📖 Как пользоваться

### 🧑‍🤝‍🧑 Для участников

1. Зайдите на сайт
2. Нажмите **"Сгенерировать билет"**
3. Получите свой уникальный номер — это ваш билет для лотереи

---

### 👨‍💼 Для админов

1. Войдите как администратор
2. Просматривайте список всех участников (новых и старых)
3. Удаляйте данные, если нужно
4. Скачивайте данные в формате Excel для отчетов

#### Команды для админов (API):

* `GET /api/users` — посмотреть участников
* `DELETE /api/users` — очистить всех
* `GET /api/users/export` — скачать Excel-файл

---

## 📋 Примеры

### Как получить билет

> Участник нажимает "Сгенерировать" и видит:
> `Ваш билет: 12`

---

### Работа админа

> Админ скачивает Excel-файл с данными:
> `Файл: users.xlsx`
> Что внутри: **Имя**, **Email**, **Номер билета**, **Дата**

✅ Сохраняет данные участников
